# auto-docs-script

**Автоматизация генерации технологических инструкций для вентиляционных систем**

Скрипт на VBA для Excel автоматически создаёт готовые документы Word, подставляя данные из таблицы в шаблон. Экономит часы рутинной работы и исключает ошибки.

---

## 📌 Описание задачи

Вручную заполнять десятки однотипных документов — долго и скучно. Данные хранятся в Excel, а шаблон Word содержит более 10 полей для замены. Скрипт делает всю работу за несколько секунд.

**Результат:** Создаётся папка с готовыми документами, каждый файл назван по шаблону `(обозначение) марка.docx`.

---

## 🛠️ Технологии

- **Язык:** VBA (Visual Basic for Applications)
- **Инструменты:** Microsoft Excel, Microsoft Word
- **Подход:** Автоматизация OLE-объектов, работа с файловой системой, обработка ошибок

---

## ⚙️ Как это работает

1. Пользователь заполняет таблицу Excel (данные по каждой системе).
2. Скрипт читает строки, фильтрует только «Вытяжные» системы.
3. Открывает шаблон Word, заменяет все плейсхолдеры вида `{{mark}}`, `{{location}}` и т.д.
4. Сохраняет готовый документ с уникальным именем в папку `Сгенерированные документы`.

## 📈 Результат

- Сократила время подготовки документов с нескольких часов до **2–3 минут**.
- Исключила ошибки, связанные с ручным копированием данных.
- Решение масштабируется на любые типы документов с похожей структурой.
